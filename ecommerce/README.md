# E-Commerce Sales Analysis Dashboard

## Project Overview
This project focuses on cleaning, analyzing, and visualizing e-commerce sales data to understand business performance, customer purchasing behavior, and product category revenue.

The project uses **Python (Pandas)** for data cleaning and **Microsoft Power BI** for data visualization and analysis.

## Objectives
- Clean and prepare raw e-commerce sales data.
- Handle missing values and duplicate records.
- Analyze revenue and sales performance.
- Identify monthly revenue trends.
- Compare revenue across product categories.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- **Python** – Data cleaning and preprocessing
- **Pandas** – Data manipulation and analysis
- **Google Colab** – Python environment
- **Microsoft Power BI** – Data visualization
- **GitHub** – Project documentation and version control

## Dataset Description
The dataset contains e-commerce order information with the following columns:

| Column | Description |
|---|---|
| order_date | Date of order |
| order_id | Order identification number |
| customer_id | Customer identification number |
| customer | Customer name |
| segment | Customer segment |
| channel | Sales channel |
| product_id | Product identification number |
| product | Product name |
| category | Product category |
| quantity | Number of units purchased |
| unit_price | Price per unit |
| discount_pct | Discount percentage |
| line_total | Final line amount |
| returned | Return status |

## Data Cleaning Process
The following operations were performed using Python and Pandas:

- Removed duplicate records.
- Standardized date and numeric data types.
- Recovered missing customer IDs using customer records.
- Recovered product information using related product records.
- Corrected inconsistent customer and product identifiers.
- Recovered financial values using available information and the sales calculation formula.
- Checked remaining missing values and data quality.

**Note:** Some values may remain missing where reliable information was unavailable. Any inferred or corrected values should be treated as estimates rather than verified original records.

## Power BI Dashboard

The dashboard contains two main visualizations:

### 1. Monthly Revenue Trend
A line chart showing how revenue changes over time, helping identify monthly sales patterns.

### 2. Revenue by Product Category
A chart comparing revenue generated by different product categories to identify strong-performing categories.

## Key Business Questions
- How does revenue change over time?
- Which product categories generate the highest revenue?
- What patterns can be observed in monthly sales performance?
